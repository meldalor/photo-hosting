# Photo Hosting

Веб-приложение для хостинга фотографий с использованием библиотеки компонентов UI.

## Описание проекта

Photo Hosting - это современное веб-приложение для загрузки, хранения и управления фотографиями. Проект реализован на React с использованием TypeScript и состоит из двух независимых модулей:
- **Frontend** - основное приложение
- **UI Library** - переиспользуемая библиотека компонентов

### Основной функционал

- **Регистрация и авторизация** - безопасная система аутентификации с хешированием паролей через Web Crypto API
- **Загрузка изображений** - загрузка фотографий с предпросмотром и валидацией (только изображения, макс. 10MB)
- **Галерея** - адаптивная сетка для отображения всех загруженных изображений
- **Управление изображениями** - просмотр метаданных и удаление фотографий
- **Защищенные маршруты** - доступ к функциям только для авторизованных пользователей

## Запуск приложения

### Установка зависимостей

```bash
# UI Library
cd ui
npm install

# Frontend
cd ../frontend
npm install
```

### Запуск в режиме разработки

```bash
# Терминал 1: Сборка ui библиотеки
cd ui
npm run build

# Терминал 2: Запуск frontend приложения
cd ../frontend
npm run dev
```

## Использование приложения

### 1. Регистрация
- Откройте приложение и перейдите на страницу регистрации
- Введите email и пароль (минимум 6 символов)
- Система автоматически авторизует вас после регистрации

### 2. Загрузка изображений
- Нажмите кнопку "Upload" в навигации
- Выберите изображение (JPEG, PNG, GIF, WEBP до 10MB)
- Просмотрите предпросмотр
- Нажмите "Upload" для сохранения

### 3. Просмотр галереи
- Все ваши изображения отображаются в адаптивной сетке
- Для каждого изображения показаны метаданные (имя файла, дата загрузки, автор, разрешение файла, размер файла)
- Нажмите "Удалить" для удаления изображения

### 4. Выход
- Нажмите кнопку "Logout" в навигационном меню
